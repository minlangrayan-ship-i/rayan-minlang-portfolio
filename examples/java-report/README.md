# Bulletin de notes — exercice Java

Code repris sans modification des fichiers du dossier de travail fourni. Il s’agit d’un exercice pédagogique, sans revendication d’utilisation en production. Le contexte exact et la contribution individuelle restent à préciser.

```sh
javac -encoding UTF-8 Main.java MathUtils.java ReportGenerator.java
java Main
```

Résultat attendu : moyenne de 11 pour les notes de mathématiques, et moyenne de 16 pour celles d’informatique. `Main` fournit les données, `MathUtils` calcule la moyenne, `ReportGenerator` affiche le rapport.

Limites : pas de validation des tableaux vides ou nuls, ni de saisie interactive. Exemple destiné à illustrer des bases Java.
